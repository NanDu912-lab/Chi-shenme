# 吃什么 · MVP 原型

🖱️ 在线直接体验（不用下载，推荐）：https://nandu912-lab.github.io/Chi-shenme/（需要科学上网）

💬 想提意见 / 参与方案讨论：Issues

一个纯静态网页原型，用来验证一件事：

「聊天式引导 + 轻量筛选」能不能帮人在 30 秒内决定今晚吃什么。

不用注册、不用联网（除了调 AI 接口）、不上传任何数据 —— 你的口味偏好只存在你自己浏览器的 localStorage 里。关掉浏览器还在，清掉浏览器数据就没了。

## 一、本地运行

### 方式 A：直接打开（最快）

下载本仓库：
- 点仓库页面右上角 Code → Download ZIP，或
- 执行 `git clone https://github.com/NanDu912-lab/Chi-shenme.git`

双击 `index.html`，用 Chrome / Edge / Firefox 打开即可。

不需要 npm install，没有任何第三方依赖，不需要构建步骤。

### 方式 B：起一个本地服务

在仓库根目录下任选一条执行：

```bash
# 装了 Python
python -m http.server 8000

# 装了 Node
npx serve .
```

然后浏览器打开 http://localhost:8000/

## 二、建议怎么走一遍（约 3 分钟）

| 步骤 | 你要做什么 | 请特别留意 |
|------|-----------|-----------|
| 1 | 打开页面，看到「今晚吃什么？」 | 第一感觉是想直接说还是先看筛选器？ |
| 2 | 点一个快捷建议（如「有点想吃辣的」） | 它有没有继续追问，还是直接给了方案？ |
| 3 | 用筛选器选预算、人数、方式 | 推荐结果跟你的选项匹配吗？ |
| 4 | 看 AI 回复的 2-3 个方案 | 是接地气的选择还是假大空？ |
| 5 | 点「换一批」或「不想吃这个」 | 它有没有记住你的反馈？ |
| 6 | 刷新页面再进来 | 你的口味偏好还在吗？ |

## 三、这个原型有什么 / 没有什么

**有（MVP 核心功能）：**

✅ 聊天式对话引导，像朋友聊天一样了解需求
✅ 轻量筛选器：预算 / 人数 / 方式（自己做 or 出去吃）
✅ 口味偏好记忆（localStorage 持久化）
✅ 每次推荐 2-3 个方案，不贪多
✅ 换一批 / 踩雷反馈机制
✅ 首次使用引导（选口味 + 常去的店）

**没有（刻意不做）：**

 账号体系、登录、云端同步
 外卖平台直接下单（只给搜索链接）
❌ 复杂的多轮追问（每次只问一个问题）
❌ 图片展示 / 精美排版
❌ 多语言支持

## 四、文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 全部代码：HTML 结构 + CSS 样式 + JavaScript 逻辑 |
| `README.md` | 项目说明 |
| `worker/` | Cloudflare Worker 代码（已弃用，国内无法访问） |
| `fc-api/` | 阿里云 FC 代码（已弃用，部署失败） |

核心逻辑都在 `index.html` 里。想改推荐策略？改 `SYSTEM_PROMPT`。想加筛选维度？改 `FILTER_OPTIONS`。想换 AI 模型？改 `MODEL` 常量。

## 五、技术说明

- 纯 HTML/CSS/JavaScript，无框架依赖
- AI 接口：通义千问 qwen-plus（dashscope.aliyuncs.com）
- API Key 内置在 `index.html` 中，仅用于课程演示
- 生产环境应通过后端代理调用 API，不要暴露 Key
